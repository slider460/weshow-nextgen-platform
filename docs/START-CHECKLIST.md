# Чек-лист на старт: что сделать вручную

Пошаговые инструкции по пунктам, которые нужны к запуску сайта.

---

## 1. Яндекс.Метрика

**Зачем:** видеть трафик, источники, поведение пользователей с первого дня.

### Шаги

1. Зайдите в [Яндекс.Метрика](https://metrika.yandex.ru/) и авторизуйтесь.
2. Нажмите **«Добавить счётчик»**.
3. Укажите адрес сайта: `https://weshow.su` (или с www, если он у вас основной).
4. Имя счётчика: например, «WESHOW — основной сайт».
5. Примите условия и создайте счётчик.
6. В настройках счётчика скопируйте **код счётчика** (блок вида `<script>(function(m,e,t,r,...)...</script>`).
7. В проекте откройте **`index.html`** и найдите комментарий `<!-- Яндекс.Метрика -->`. Вставьте скопированный код счётчика **сразу после** этого комментария (перед `</head>` или в начало `<body>` — как в инструкции Яндекса; обычно рекомендуют перед `</head>`).
8. Сохраните файл, задеплойте и проверьте в интерфейсе Метрики, что счётчик в статусе «Данные поступают» (может занять несколько минут).

**Важно:** не публикуйте код счётчика в открытых репозиториях, если в нём указан ваш уникальный ID. Можно вынести ID в переменную окружения и подставлять при сборке — тогда в репозитории оставить только плейсхолдер.

## 2. Один основной адрес сайта (www или без www)

**Зачем:** одна главная версия URL для индексации и отчётов, без дублей.

### Шаг 1: Проверить, как открывается сайт

- Откройте в браузере: `https://weshow.su` и `https://www.weshow.su`.
- Посмотрите, оба ли открываются, редирект ли с одного на другой, какой URL в итоге в адресной строке.

### Шаг 2: Выбрать главное зеркало

Рекомендация: **без www** — `https://weshow.su` (так уже задано в canonical и в sitemap).

### Шаг 3: Указать зеркало в Яндекс.Вебмастер

1. Зайдите в [Яндекс.Вебмастер](https://webmaster.yandex.ru/), откройте сайт.
2. **Настройки** → **Главное зеркало**.
3. Выберите `https://weshow.su` (или с www, если решили иначе).
4. Сохраните.

### Шаг 4: Настроить редирект (если оба адреса открываются)

Если и `weshow.su`, и `www.weshow.su` открываются по отдельности, нужно настроить редирект с неглавного на главный.

- **Netlify:** в корне проекта создайте файл `public/_redirects` (или `netlify.toml` с правилами). Пример для редиректа www → без www:
  ```
  https://www.weshow.su/*  https://weshow.su/:splat  301!
  ```
- **Другой хостинг:** настройте 301-редирект в панели (часто раздел «Домены» или «Редиректы»). Правило: с `https://www.weshow.su` на `https://weshow.su`.
- **Nginx:** добавьте server для www с `return 301 https://weshow.su$request_uri;`.

После этого при открытии www пользователь должен попадать на версию без www.

## 3. Ссылка «Перейти к контенту»

**Зачем:** доступность для клавиатуры и скринридеров.

В коде уже добавлено:

- Ссылка «Перейти к контенту» в начале страницы (видна при фокусе с клавиатуры).
- Контейнер с `id="main"`, куда ведёт эта ссылка.

Ничего вручную делать не нужно — достаточно задеплоить текущую версию. Проверка: откройте сайт, нажмите Tab — первой подсвеченной должна быть эта ссылка; Enter переносит к основному контенту.

## 4. Ширина и высота у главных картинок

**Зачем:** меньше сдвиг верстки при загрузке (CLS), стабильнее метрики.

В коде добавлены примеры для блока оборудования на главной. Для остальных картинок можно делать по тому же принципу.

**Как добавить вручную:**

- Для обычного `<img>` задайте атрибуты `width` и `height` в пикселях (реальные размеры изображения или пропорции, которые вы соблюдаете). Пример:
  ```html
  <img src="..." alt="..." width="1200" height="630" loading="lazy" />
  ```
- Либо у контейнера картинки задайте фиксированное соотношение сторон через классы, например Tailwind: `aspect-video` (16:9) или `aspect-[21/9]`, и не задавайте height у самого img — тогда CLS тоже уменьшится.

**Где особенно полезно:** hero-блок на главной, крупные картинки в портфолио и в первом экране ключевых страниц.

## 5. FAQ-разметка (расширенные сниппеты)

**Зачем:** блок вопросов-ответов на странице «Технологичные выставочные стенды» может показываться в расширенных сниппетах в поиске.

В коде уже добавлена разметка **FAQPage** (JSON-LD) для этой страницы: при открытии раздела с FAQ в `<head>` подставляется скрипт со структурными данными. Дополнительно ничего делать не нужно — только задеплоить.

Проверка: после деплоя откройте [инструмент проверки расширенных результатов Google](https://search.google.com/test/rich-results) или проверку разметки в Вебмастере Яндекса и укажите URL страницы «Технологичные выставочные стенды».
