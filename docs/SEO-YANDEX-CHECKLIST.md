# Чек-лист: индексация и продвижение в Яндексе

По [документации Яндекса](https://yandex.ru/support/webmaster/): индексирование, robots.txt, Sitemap.

## Сделано в проекте

- **robots.txt** — в `public/robots.txt`: блок `User-agent: Yandex`, `Allow: /`, `Disallow: /mail/`, директива `Sitemap: https://weshow.su/sitemap.xml`.
- **sitemap.xml** — в `public/sitemap.xml`: главная, about, contact, services (и подстраницы), portfolio (и кейсы), equipment (и типы), team, privacy.
- **index.html** — в `<head>` добавлен комментарий, где вставить мета-тег подтверждения Яндекса.

## Что сделать вручную

1. **Добавить сайт в Яндекс.Вебмастер**  
   https://webmaster.yandex.ru/ → добавить сайт `https://weshow.su`.

2. **Подтвердить права на сайт**  
   В Вебмастере выбрать способ «Мета-тег»: скопировать значение `content` и вставить в `index.html`:
   ```html
   <meta name="yandex-verification" content="ВАШ_КОД_ИЗ_ВЕБМАСТЕРА" />
   ```
   Разместить в `<head>` (рядом с комментарием про yandex-verification).

3. **Проверить доступность файлов** (после деплоя):
   - `https://weshow.su/robots.txt` — ответ **200**, в теле есть `Sitemap: https://weshow.su/sitemap.xml`.
   - `https://weshow.su/sitemap.xml` — ответ **200**, валидный XML.

4. **В Вебмастере** загрузить sitemap: указать URL `https://weshow.su/sitemap.xml` (или добавить через «Индексирование» → «Файлы Sitemap»).

5. **Не закрывать от индекса** важные страницы в robots.txt; служебные (например `/mail/`) уже закрыты.

## Рекомендации Яндекса (кратко)

- **robots.txt** — только латиница в путях и директивах; кириллица не допускается.
- **Sitemap** — URL не длиннее 2048 символов; при большом числе URL — разбить на несколько sitemap или индексный sitemap.
- **404** — отдавать корректный код; не использовать его для редиректа на главную.
- **Last-Modified** — при возможности отдавать для статических страниц (для SPA часто не требуется).

После выполнения пунктов 1–4 сайт готов к индексации Яндексом; мониторинг — в разделе «Индексирование» Вебмастера.
