# 🌐 Настройка Cloudflare для доступности из России

## Проблема
Сайт weshow.su не доступен из России без VPN, хотя домен не заблокирован Роскомнадзором. Причина - ограничения Vercel для российских IP.

## Решение
Использовать Cloudflare как прокси перед Vercel. Cloudflare имеет хорошую инфраструктуру в России и не блокирует российские IP.

---

## 📋 Пошаговая инструкция

### Шаг 1: Регистрация в Cloudflare

1. Перейдите на https://dash.cloudflare.com/sign-up
2. Зарегистрируйтесь (можно через Google/GitHub)
3. Выберите **бесплатный план** (Free)

### Шаг 2: Добавление домена

1. В Dashboard Cloudflare нажмите **"Add a Site"**
2. Введите: `weshow.su`
3. Нажмите **"Add site"**
4. Выберите план: **Free** (бесплатный)
5. Нажмите **"Continue"**

### Шаг 3: Проверка DNS-записей

Cloudflare автоматически обнаружит текущие DNS-записи. Проверьте:

- ✅ Должна быть A-запись: `@` → `216.198.79.1` (IP Vercel)
- ✅ Должна быть A-запись: `www` → `216.198.79.1` (или CNAME)

**Важно:** Убедитесь, что обе записи имеют **оранжевое облачко** (прокси включен) 🟠

### Шаг 4: Изменение DNS-серверов в reg.ru

Cloudflare покажет вам **2 новых DNS-сервера**, например:
```
ns1.cloudflare.com
ns2.cloudflare.com
```

**Что нужно сделать:**

1. Войдите в панель управления доменом на reg.ru
2. Перейдите в раздел **"DNS-серверы"** или **"Управление DNS"**
3. Измените DNS-серверы на те, что дал Cloudflare:
   - Удалите: `ns1.reg.ru` и `ns2.reg.ru`
   - Добавьте: `ns1.cloudflare.com` и `ns2.cloudflare.com`
4. Сохраните изменения

### Шаг 5: Ожидание распространения DNS

- Обычно занимает **15-30 минут**, максимум **24 часа**
- Cloudflare покажет статус: **"Pending"** → **"Active"**

### Шаг 6: Настройка SSL/TLS

1. В Cloudflare Dashboard перейдите в **SSL/TLS**
2. Выберите режим: **"Full"** (не "Flexible")
3. Это обеспечит шифрование между пользователем и Cloudflare, и между Cloudflare и Vercel

### Шаг 7: Настройка кеширования (опционально)

1. Перейдите в **Caching** → **Configuration**
2. Рекомендуемые настройки:
   - **Caching Level**: Standard
   - **Browser Cache TTL**: 4 hours
   - **Always Online**: On

### Шаг 8: Проверка работы

После активации DNS:

1. Проверьте сайт из России (без VPN)
2. Проверьте скорость загрузки
3. Убедитесь, что все работает корректно

## 🔧 Дополнительные настройки (опционально)

### Настройка Page Rules для Vercel

1. Перейдите в **Rules** → **Page Rules**
2. Создайте правило:
   - **URL**: `weshow.su/*`
   - **Settings**:
     - Cache Level: Standard
     - Browser Cache TTL: 4 hours

### Настройка Speed Optimization

1. Перейдите в **Speed** → **Optimization**
2. Включите:
   - ✅ Auto Minify (HTML, CSS, JS)
   - ✅ Brotli compression
   - ✅ Rocket Loader (опционально)

---

## ⚠️ Важные моменты

1. **Не удаляйте проект в Vercel** - Cloudflare только проксирует запросы
2. **DNS-серверы** должны быть изменены в reg.ru на Cloudflare
3. **SSL-режим** должен быть "Full", не "Flexible"
4. **Ожидание** - DNS может распространяться до 24 часов

---

## 🆘 Если что-то не работает

1. Проверьте DNS-серверы в reg.ru - должны быть Cloudflare
2. Проверьте статус в Cloudflare Dashboard - должен быть "Active"
3. Проверьте SSL-режим - должен быть "Full"
4. Очистите кеш браузера и DNS: `ipconfig /flushdns` (Windows) или `sudo dscacheutil -flushcache` (Mac)
