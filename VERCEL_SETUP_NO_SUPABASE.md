# 🚀 Настройка Vercel БЕЗ Supabase

## ✅ Важная информация

**Проект полностью локальный!**
- ❌ Supabase НЕ используется
- ❌ Переменные окружения НЕ требуются
- ✅ Все данные хранятся локально в проекте

## 📋 Быстрая настройка нового проекта

### 1. Создание проекта

1. Откройте https://vercel.com/new (через VPN)
2. Нажмите "Add New..." → "Project"
3. Выберите репозиторий: `slider460/weshow-nextgen-platform`

### 2. Настройки проекта

**Framework Preset:** `Vite`

**Build Settings:**
```
Root Directory: ./ (пусто)
Build Command: npm run build
Output Directory: dist
Install Command: npm install
Development Command: npm run dev
```

**Environment Variables:**
⚠️ **НЕ ДОБАВЛЯЙТЕ НИКАКИХ ПЕРЕМЕННЫХ!**
- Проект работает без переменных окружения
- Все данные локальные

### 3. Git интеграция

**Settings** → **Git:**
- Production Branch: `main`
- Auto-deploy: ✅ включен

### 4. Домен

**Settings** → **Domains:**
- Добавьте: `weshow.su`
- Настройте DNS записи

### 5. Деплой

Нажмите **"Deploy"** и дождитесь завершения (2-5 минут)

## 🎯 Проверка

После деплоя:
- ✅ Сайт должен открываться на https://www.weshow.su
- ✅ Все данные должны загружаться локально
- ✅ Не должно быть ошибок в консоли браузера

## ❌ Если были проблемы с Supabase

Если ранее были настроены переменные Supabase в Vercel:
1. **Settings** → **Environment Variables**
2. **Удалите** все переменные с `VITE_SUPABASE_*`
3. Сохраните изменения
4. Сделайте новый деплой

## 🔍 Почему не нужны переменные?

В коде есть fallback значения:
- Если переменные не заданы - используется mock клиент
- Все данные загружаются из локальных файлов
- Проект работает полностью автономно
